# Portfolio

Personal portfolio site — Shashank Subba Dongol, BSc (Hons) Computer Science (First Class Honours), Leeds Beckett University.

A single self-contained `index.html`: no build step, no framework, no dependencies beyond Google Fonts. Open the file in a browser or serve the folder statically.

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | The whole site — markup, styles and behaviour |
| `strived*.png` | Strived screenshots |
| `nfc*.png` | Tap-In NFC attendance screenshots |
| `softfocus*.png` | Soft Focus screenshots |
| `ghostarena*.png` | Ghost Arena screenshots |
| `ghostarenavid.mp4` | Ghost Arena gameplay clip |
| `profile picture.jpg` | Hero photo |

## Projects covered

- **Strived** — two-sided graduate job marketplace (Next.js, TypeScript, Tailwind CSS)
- **Tap-In** — offline-first NFC classroom attendance platform (Node.js, Express, SQLite, MIFARE/PC-SC)
- **Soft Focus** — AI wellness app for neurodivergent students, built solo at LeedsHack 2026 (React Native, Firebase, Gemini 2.0 Flash)
- **Ghost Arena** — wave-survival arena shooter (Godot 4, GDScript, Android)
- **Smart Plant Monitoring System** — final year IoT project (ESP32, C++, Kotlin, Android)

Each project card opens a modal with a screenshot carousel and a full write-up.

## Running locally

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>. Opening `index.html` directly via `file://` also works.
